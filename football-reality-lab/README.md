# ELEVEN — Football Reality Lab
A browser-based interactive football simulation prototype exploring emergent match dynamics.

## Run locally
```bash
python server.py
```
Open http://localhost:8080.

## Prototype features
- Animated tactical pitch and stochastic match events
- Match clock, score, possession, illustrative xG and workload
- Tactical and weather controls
- Individual player profiles with distinct attributes and tendencies
- Career ecosystem concept with multi-variable weekly decisions
- Physics observatory explaining the intended model

## Important scope note
This alpha is a front-end simulation prototype. It does not yet implement validated 3D ball aerodynamics, deformable turf, net cloth, skeletal biomechanics, persistent saves, or real-world club/player data. The teams and ratings are fictional and illustrative.
