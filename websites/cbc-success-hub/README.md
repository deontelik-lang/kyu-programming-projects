# CBC Success Hub — Free Exam Practice

A responsive, single-page study site containing original KNEC-style practice papers for KPSEA, KJSEA / Grade 9, Grades 7–8, Grade 10 transition practice, KCSE revision, and teachers.

## Features
- Search and category filters across the free sample library.
- Original, challenging questions with worked marking guides.
- Timed attempts, per-question progress checkboxes, reveal/hide solutions, and print / save as PDF.
- No payment gateway, account, phone-number collection, or user analytics in this demo.
- KICD/KNEC context links and a clear disclaimer that the original practice material is not official KNEC content.

## Run locally
This is a static site. Open `index.html` in a browser or serve this folder with any static web server.

## Curriculum note
The Grade 9 Mathematics practice sample draws on the KICD Grade 9 Mathematics design, including the `Indices and Logarithms` sub-strand and common logarithms. The papers are newly written practice items, not official examinations or copied past papers.

- KICD Grade 9 Mathematics design: https://kicd.ac.ke/wp-content/uploads/2024/09/GRADE-9-MATHEMATICS.pdf
- KNEC timetables: https://www.knec.ac.ke/timetables/
- KNEC 2026 KCSE timetable: https://www.knec.ac.ke/2026-kcse-timetable/

## Hosting note
The application has been published as a static sub-path on an existing BasicDeploy static-server container to avoid replacing any existing application. The website source is maintained in this repository under `websites/cbc-success-hub/`.
